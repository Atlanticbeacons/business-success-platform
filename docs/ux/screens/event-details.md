# Event Details

## Goal

The Event Details screen helps members understand the value, logistics, and relevance of a specific event before deciding whether to attend.

Its purpose is to give members enough information to confidently register and prepare for the event.

---

## User Questions

When members access this screen, they should be able to answer the following questions:

* What is this event about?
* Why is it relevant to my business?
* What will I learn or gain?
* When and where is it happening?
* Who is it for?
* How do I register?
* What should I know before attending?

---

## Success Criteria

A successful Event Details experience enables members to:

* Quickly understand the purpose and value of the event.
* Determine whether the event is relevant to their business.
* See all important event logistics.
* Register easily.
* Understand what to expect before attending.
* Access event information after registering.

---

## Sections

### 1. Event Overview

Provides a concise summary of the event.

Information includes:

* Event Name
* Date
* Time
* Location or Online
* Event Type
* Organizer
* Registration Status

Purpose:

* Help members understand the event at a glance.

---

### 2. Why This Event Is Recommended

Explains why the event is relevant to the member.

Examples:

* Matches your business goal.
* Supports your current Recommended Action.
* Relevant to your industry.
* Provides access to a network or opportunity relevant to your business.

Purpose:

* Make event recommendations transparent and useful.

---

### 3. About the Event

Provides detailed information about the event.

Information may include:

* Description
* Agenda
* Speakers
* Topics Covered
* Intended Audience
* Expected Outcomes

Purpose:

* Help members determine whether the event is worth attending.

---

### 4. Event Logistics

Provides practical information needed to attend.

Information includes:

* Date
* Time
* Time Zone
* Location
* Online Meeting Link, when applicable
* Accessibility Information, when available

Primary Action:

* Add to Calendar

---

### 5. Registration

Allows members to register for the event.

Information includes:

* Registration Status
* Capacity
* Registration Deadline
* Registration Requirements

Primary Action:

* Register

When registration is managed externally, the member should be redirected to the official registration process.

---

### 6. Related Opportunities

Displays other relevant events, benefits, resources, or support options.

Purpose:

* Help members continue progressing after discovering the event.

Primary Actions:

* Explore Related Events
* View Related Resources
* Find Related Support

---

## Primary Actions

Members should be able to:

* Register for the event.
* Cancel registration when permitted.
* Add the event to their calendar.
* View event logistics.
* Access the online event link when applicable.
* Share the event.
* Explore related opportunities.

---

## Business Rules

### Event Information

* Event date, time, and location must be clearly displayed.
* Online events must clearly explain how members will access them.
* The relevant time zone must be displayed.
* Past events cannot be presented as upcoming events.

### Recommendations

* The reason for recommending an event should be displayed when the event is personalized.
* Recommendations should consider the member's active business, goals, interests, and current context.

### Registration

* Registration status must be clearly displayed.
* Members cannot register twice for the same event.
* Events with limited capacity must display availability when possible.
* Registration deadlines must be displayed when applicable.
* Members can cancel registration only when cancellation is permitted.

### External Registration

* Events managed by external organizations may redirect members to the official registration website.
* The platform must clearly communicate when the member is leaving the platform.
* External registration links should point to the official event source.

### Calendar

* Registered events should be available to add to the member's calendar.
* Calendar information must reflect the confirmed event date and time.

## Empty States

### Registration Unavailable

Message:

"Registration isn't available right now."

Primary Action:

Contact NYWCC Support

---

### Event Details Incomplete

Message:

"Some event information isn't available yet."

Primary Action:

Check Back Later

---

### Event Cancelled

Message:

"This event has been cancelled."

Primary Action:

Explore Upcoming Events

---

### Event Full

Message:

"This event has reached capacity."

Primary Action:

Explore Similar Events
